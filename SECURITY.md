# Security policy

UPDC is scientific image-reconstruction software and is not intended to be a
security boundary. Nevertheless, please report suspected security issues
privately when possible.

## Supported versions

The current `1.1.x` release line is supported for packaging, build, and
interface fixes. Numerical changes to the frozen v17 core require a new core
freeze and scientific validation.

## Reporting

Use the repository's **Security** tab and GitHub private vulnerability
reporting / security advisories when available. If private reporting is not
enabled, open a minimal public issue requesting maintainer contact and do not
include exploit details or sensitive data in the issue.

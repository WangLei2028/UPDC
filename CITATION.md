# Citing UPDC

UPDC is released under the MIT License. For scholarly or other publication use
of the UPDC code, its algorithmic implementation, or scientific results
produced with UPDC, the UPDC project requires citation of **both** papers below.
This scientific citation policy is separate from the MIT software license and
does not modify the permissions in `LICENSE`.

## Required references for publications

1. Wang, L., Li, G., & Kang, X. 2022, *Towards super-resolution via iterative
   multi-exposure coaddition*, **MNRAS, 517, 787**.
   doi: **10.1093/mnras/stac2664**

2. Wang, L., Shan, H., Nie, L., et al. 2025, *UPdec-Webb: A Data Set for
   Coaddition of JWST NIRCam Images*, **ApJS, 276, 36**.
   doi: **10.3847/1538-4365/ad9566**

## BibTeX

```bibtex
@article{Wang2022UPDC,
  author  = {Wang, L. and Li, G. and Kang, X.},
  title   = {Towards super-resolution via iterative multi-exposure coaddition},
  journal = {Monthly Notices of the Royal Astronomical Society},
  volume  = {517},
  pages   = {787},
  year    = {2022},
  doi     = {10.1093/mnras/stac2664}
}

@article{Wang2025UPdecWebb,
  author  = {Wang, L. and Shan, H. and Nie, L. and others},
  title   = {UPdec-Webb: A Data Set for Coaddition of JWST NIRCam Images},
  journal = {The Astrophysical Journal Supplement Series},
  volume  = {276},
  pages   = {36},
  year    = {2025},
  doi     = {10.3847/1538-4365/ad9566}
}
```

GitHub also reads the machine-readable `CITATION.cff` file in the repository
root.
